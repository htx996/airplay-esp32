# AirPlay ESP32 Firmware Packages

生成时间：2026-05-25

本次构建包含以下定制内容：

- 从 `HomePod mini` (`AudioAccessory5,1`)
- 切换为 `HomePod` (`AudioAccessory1,1`)
- 中文 AP 配网页面
- 运行时 GPIO 配置
- 系统面板新增 `开启 AP` 与 `重置 Wi-Fi` 按钮

## 什么时候用哪个

- 想一次烧录完成 bootloader、分区表、otadata、应用和网页文件系统：
  用对应板型的 `merged` 单文件包
- 对 `ESP32-S3 Generic / N16R8`：
  用 `esp32s3-merged-16mb-20260525.bin`
- 设备当前已经能正常运行同板型、同 8MB 分区方案的固件，并且网页 OTA 可用：
  用对应的 `ota-firmware-20260525.bin`

## ESP32-S3 说明

- `esp32s3` 目标按 16MB flash 头信息构建，适合 `ESP32-S3-N16R8`
- 这个项目当前分区表实际使用的是 flash 前 8MB，所以合并出来的单文件大小约为 8MB，这是正常现象

## 不建议直接 OTA 的情况

- 当前设备刷的是不同板型的固件
- 当前设备刷的是不同 flash 大小或不同分区表的固件
- 当前设备的网页/OTA 功能异常
- 想顺便重建 bootloader、分区表或网页文件系统

这些情况直接全新烧录对应板型的 `merged` 单文件包更稳妥；
对 `ESP32-S3-N16R8`，就是 `esp32s3-merged-16mb-20260525.bin`。
