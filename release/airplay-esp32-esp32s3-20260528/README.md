# ESP32-S3 Release 2026-05-28

适用板型：`ESP32-S3-N16R8`

## 文件说明

- `esp32s3-merged-16mb-20260528.bin`
  全量单文件包，包含 bootloader、分区表、OTA 数据、应用固件和 `SPIFFS` 网页资源。
- `esp32s3-ota-firmware-20260528.bin`
  应用 OTA 包，只更新程序本体，不更新网页资源。
- `esp32s3-spiffs-storage-20260528.bin`
  网页资源 OTA 包，只更新 `storage / SPIFFS` 分区，不更新程序本体。

## 这版变化

- 当前若设备已在通电运行，会忽略当前这次上电，从下一次 `上电 -> 断电` 才开始算第 `1` 轮
- 每一轮必须在 `5` 秒内完成；超时则清零重计
- 连续完成 `5` 轮 `上电 -> 断电` 后，下一次上电自动清空已保存 Wi‑Fi，并回到 AP 配网模式
- 只清除 Wi‑Fi 凭据，不影响设备名、GPIO、EQ、音量等其他配置

## 什么时候用哪个

- 第一次刷入，或者想把程序和网页资源一次性都更新：
  直接刷 `esp32s3-merged-16mb-20260528.bin`
- 只需要升级这次新增的“5 秒窗口内完成 5 轮通断电后回 AP 配网”逻辑：
  用 `esp32s3-ota-firmware-20260528.bin`
- 只改网页资源时：
  用 `esp32s3-spiffs-storage-20260528.bin`
